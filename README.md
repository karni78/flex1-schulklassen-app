# Flex 1 – Schulklassen-App

Moderne, responsive Schulklassen-Web-App mit Passwortschutz.

## Enthalten
- geschützter Klassenbereich
- gemeinsamer Chat mit Reaktionen
- Flex-1-Stundenplan als echte HTML-Ansicht
- Bildergalerie
- Dokumente mit Download
- Termine und Neuigkeiten
- Adminbereich für Info, Uploads und Löschung
- modernes mobiles UI mit geschwungenen Farbflächen

## Start
1. Node.js 18+ installieren
2. `npm install`
3. `.env.example` nach `.env` kopieren und Passwörter/Session-Secret ändern
4. `npm start`
5. `http://localhost:3000` öffnen

Die Anwendung ist für den Betrieb hinter HTTPS gedacht. Für einen öffentlichen Einsatz sollten zusätzlich sichere Secrets, Reverse Proxy/HTTPS, Backups und Datenschutzanforderungen eingerichtet werden.
